# Repository Instructions

## Commit attribution

Use `Travis Huff <huff.travis@gmail.com>` as the primary author and committer
for every commit Codex creates or amends in this repository.

For those Codex-created or Codex-amended commits, include this trailer exactly
once:

```text
Co-authored-by: Codex <codex@openai.com>
```

Do not add the Codex trailer to commits that Codex did not create or amend.
Do not install a Git hook that adds the trailer to every commit, because
human-only commits should retain Travis Huff as their sole author.

Do not rewrite published commit history or release tags solely to change
attribution.
